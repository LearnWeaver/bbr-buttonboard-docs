MIDI#

In midi mode the board is a USB MIDI controller called BBR Button Board. Music programs, lighting desks (QLC+, Lightkey) and stream tools (Bitfocus Companion, or OBS with a MIDI plugin) all read it, with no driver, on Windows, macOS, Linux, iPad, Android and ChromeOS.

It is also the one mode in which the program can light the keys, the way it lights pads on a commercial controller.

To turn it on, see USB modes: pick MIDI, Save, unplug and plug back in.

MIDI mode has not yet been tested with real music software. Try it with your own program before relying on it.

Choosing what a key sends#

Go to Configure, select a key, and choose under Sends:

Kind Pressed Let go
Note Note On, velocity 127 Note Off
Controller (CC) That controller at 127 That controller at 0
Program change Program change, once Nothing

Pick the number, 0 to 127, and the channel, 1 to 16. Note 60 is middle C. Most programs call it C4; Ableton and FL Studio call it C3. The app shows both the number and the name.

A key that has no button number gets a spare one by itself.

  • The keys have no velocity: every note is 127.
  • A controller stays at 127 for as long as the key is held, so CC 64 on a key works as a sustain pedal.
  • Two keys on the same note sound it once. The note ends when the last of them is let go.

Learn from the computer#

Press Learn from the computer…, then, in your program, light the pad you want or move the control. The next note or controller the program sends is taken for that key.

Lights#

When the program sends a key’s own note or controller back to the board, the key lights in its LED colour, or white if it has none. A Note Off, or a value of 0, turns it dark. So a program that lights its pads on a controller lights them here too, with nothing to set up beyond choosing the note.

Until the program first sends to a key, the key shows its normal colour. A program change has no light.

Knobs#

Select an encoder and tick Send a controller under Knob. Choose the CC number and channel.

The knob sends relative values: 64 plus the number of clicks since the last message, so 65 is one click clockwise and 63 one click anticlockwise. In your program, set the control to Relative (64). Some programs call it Relative 2 or binary offset.

A knob without a controller presses its two direction buttons, one press per click, and each sends its own note.

Safety#

  • Binding a key, or any change to the configuration, ends every sounding note first.
  • A tile that is unplugged or stops answering ends its notes at once.
  • The Test patterns on Diagnose are refused in midi, as they would play every note at once.
  • There is no time limit on a held note. A sustain pedal held for minutes is normal.

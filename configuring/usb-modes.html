USB modes#

The board can show up on USB as five different devices. The tiles, bindings, LED colours and display tiles are the same in all of them. What changes is what the computer sees when a key is pressed.

Mode In the config app The computer sees For
frc FRC gamepad A joystick with 32 buttons and 4 axes The FRC Driver Station. The default
xinput FTC (Xbox pad) An Xbox 360 pad The FTC Driver Station
desk Keyboard & media A keyboard, media keys and a mouse Volume knobs, media keys, shortcuts, macro pads. See Keyboard and media keys
midi MIDI A USB MIDI controller Music programs, lighting desks, stream tools. See MIDI
sim Sim (128 buttons) A joystick with 128 buttons, 8 axes and a hat Flight and driving sims. See Flight and driving sims

desk, midi and sim are not for competition use. Neither Driver Station reads them as a controller.

desk, midi and sim need main module firmware 0.4.0 or newer. An older board refuses them; update it on the Firmware screen first. See Updating the firmware.

Switching modes#

  1. Pick the mode under Mode at the top of the Configure inspector, or on the Connect screen.
  2. Press Save.
  3. Unplug the board and plug it back in.

The board only changes what it is when it is replugged. Until then the app shows The board still reports as frc, and the keys keep doing what they did before.

No drivers are needed in any mode, on Windows, macOS, Linux or ChromeOS.

What carries over#

Each mode keeps its own settings in the same saved configuration, so switching back and forth loses nothing. A key can be button 5 in frc, Ctrl+Shift+M in desk and note 60 in midi all at once. Only the setting for the current mode is used.

The inspector shows only the current mode’s options. Switch the mode and it shows the other mode’s options instead.

The config app in each mode#

frc, desk, midi and sim all keep the config channel, so the app connects to the board as usual.

xinput has no config channel. To change anything on a board in xinput, hold the CFG button on the main module while plugging it in. That starts it in a mode the app can reach, whatever is stored.

Testing#

The Test card on Diagnose is refused in desk and midi. Its patterns press every button at once, and in those modes that would mean every shortcut or every note together. Press the keys themselves instead; Pressed now shows them arriving.

Plugging it together#

The chain#

Every board — the main module and every tile — has two identical connectors, wired in parallel. Run a cable from one board to the next in any order you like:

main module ──── mx9 ──── mx9 ──── enc2
     │                               │
terminator                      terminator
  • Order does not matter. The main module finds tiles by asking, not by counting along the cable.
  • Both connectors on a board are the same. There is no “in” and no “out”.
  • Cables are straight through. Pin 1 to pin 1. There is no crossover cable in this system.
  • Up to 31 tiles, and up to about 4 m of cable in total.

Splitting the chain#

A splitter is a small square board with four connectors wired in parallel. Use one where the cable wants to go in more than one direction, for example along both sides of a panel:

main module ──── mx9 ──── splitter ──── mx9 ──── enc2
     │                       │                    │
terminator                  mx4               terminator

The bus doesn’t care: tiles on a branch are found and addressed exactly like tiles on the main run. What changes is where the terminators go:

  • Still exactly two terminators, at the two ends that are farthest apart along the cable. In the drawing that’s the main module and the enc2. The mx4 on the short branch gets none.
  • Never a terminator on a splitter, unless that splitter is itself at one of the two far ends.
  • No loops. Never cable back to a board that is already on the bus. Nothing detects a loop, and it leaves the bus with no ends to terminate.
  • Count the branches in the 4 m. The limit is the total of every cable on the bus.

Terminators go at both ends#

On a plain chain, the two connectors that end up with nothing plugged into them — one on the main module, one on the last tile — each take a terminator. With a splitter, see the rules above.

Fit both. A chain missing a terminator usually works on the bench and then loses tiles under vibration or on a longer cable, which reads as a key that “sometimes doesn’t work” rather than as a wiring fault.

If your panel is permanently installed and the main module sits at one end of the chain, you can use the main module’s built-in termination jumper instead of a terminator in its spare connector. One or the other, not both.

Power#

The whole panel runs off the USB cable. There is nothing else to plug in.

That budget is not unlimited, and LEDs are what spend it. The main module works out the worst-case draw of every tile on the chain and turns the global LED brightness down until the panel fits the budget — so an over-lit panel dims rather than browning out mid-match. If you are running from a port that can supply more than the default, raise the budget in the config app. See LED colours.

Adding a tile mid-season#

Plug it into a spare connector, moving the terminator to the new end of the chain. The main module gives it an address by itself the next time it is powered on. Nothing that was already bound changes.

The one thing to know: bindings are stored per tile position, not per physical board. If you swap a faulty tile for an identical one, the replacement inherits the old one’s bindings automatically. If you add a second tile of the same kind, it is a new tile and starts unbound. Binding buttons covers what to do when the board cannot tell which case it is looking at.

Cable pinout#

Six-way JST GH, 1.25 mm pitch. You only need this if you are making cables.

Pin Signal
1 GND
2 GND
3 B (−)
4 A (+)
5 5 V
6 5 V

Ground and 5 V are doubled to carry the current an illuminated arcade tile can draw. The differential pair sits in the middle, away from the power pins.

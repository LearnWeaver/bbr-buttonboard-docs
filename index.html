BBR Button Board#

A button box you build out of tiles. One USB cable to the Driver Station.

The Button Board is a modular control panel for FIRST robotics. A main module plugs into the Driver Station laptop over USB and presents itself as a game controller. Everything a driver actually touches lives on tiles — nine-key keypads, single keys, arcade buttons, rotary encoders — daisy-chained off the main module on one four-wire cable.

  • Build the panel you want. Tiles chain in any order. Add one mid-season without rewiring anything.
  • No code on the robot. The board is an ordinary game controller. Your OpMode or robot code reads buttons exactly the way it reads a gamepad.
  • Works with both Driver Stations. An FRC-friendly HID gamepad with 32 buttons, or an XInput gamepad for the FTC Driver Station — one setting, no hardware change.
  • Configured in the browser. Bind a key by pressing it. No firmware rebuild, no config file.
  • LEDs your robot drives. Tiles with RGB keys can be lit from a companion app on the Driver Station laptop, so the panel reacts to what the robot is doing.

How it fits together#

Driver Station laptop
        │  USB-C
   ┌────┴──────┐      RS-485, one cable per link
   │   main    ├──── tile ──── tile ──── tile ───┤
   │  module   │                                 │
   └───────────┘                          terminator plug

The main module polls every tile in turn, collects which keys are down, and sends one USB report. From the Driver Station’s point of view there is a single game controller with 32 buttons on it — it never learns that there are tiles at all.

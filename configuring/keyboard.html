Keyboard and media keys#

In desk mode the board is a keyboard, a set of media keys and a mouse. Use it for a volume knob, play and pause, keyboard shortcuts for OBS or a video editor, or a scroll wheel. It needs no driver.

So far desk has been tried on macOS, where media keys and scrolling work. It is a standard USB keyboard, so Windows, Linux, ChromeOS, iPad and Android should take it the same way; check yours before relying on it.

To turn it on, see USB modes: pick Keyboard & media, Save, unplug and plug back in.

Choosing what a key sends#

Go to Configure, select a key, and use the Sends section of the inspector. Pick any of:

  • A media key: volume up and down, mute, play/pause, next and previous track, screen brightness.
  • F13 to F24. No real keyboard has these keys, so apps such as OBS, Discord or a video editor can use them as shortcuts that clash with nothing.
  • A mouse action: left, right or middle click, or one step of the scroll wheel.
  • A shortcut. Click the modifiers (Ctrl, Shift, Alt, Cmd/Win) and choose the key from the list. This is how to set shortcuts the computer keeps for itself, such as Cmd+Tab or Ctrl+W.
  • Record a shortcut from the laptop’s keyboard, or type one in the box: ctrl+shift+m, gui+l, f13.

A key that has no button number gets a spare one by itself, so you never have to pick a number.

The key’s action is held for as long as the key is held, as on a real keyboard. Holding a key with a modifier on it (Shift, say) changes what another key sends, exactly as on a keyboard.

Keys are positions, not letters. The board sends the key at that place on a US keyboard, which is what every USB keyboard does. On a French layout, a types q. Shortcuts behave the same as on the computer’s own keyboard.

One key sends one shortcut. Typing a word, or a sequence of several shortcuts, is not supported.

Knobs#

In desk mode each click of an encoder is one press of a button. Select the knob and choose a preset under Knob:

  • Volume knob
  • Scroll wheel
  • Brightness
  • Next / previous track

Each preset sets both directions at once. To send something else, set the knob’s two Direction buttons and give each button an action.

Showing the volume on a display#

The knob and mute key work with nothing running on the computer. To also see the volume, run ds_volume.py on the laptop. It draws the computer’s volume as a bar on a disp2 and follows it as the knob turns. While the sound is muted it shows MUTED and lights the mute key red.

pip install bbr-buttonboard
python ds_volume.py

It reads the volume from the computer itself, so the bar also follows the keyboard’s own volume keys. macOS and Linux work as they are; Windows needs pip install pycaw as well. Close the config app first: only one program can talk to the board at a time.

Safety#

  • A key held for more than 60 seconds is released, and stays released until it is let go. A stuck key never types forever. The board’s fault event says stuck when this happens.
  • Binding a key, or any change to the configuration, releases every key first, so nothing is left held down.
  • A tile that is unplugged or stops answering releases its keys at once.
  • The Test patterns on Diagnose are refused in desk, as they would press every shortcut at once.

Lock lights#

The board reports the computer’s Caps Lock, Num Lock and Scroll Lock state on the config channel as a lock event. See Serial command reference.

Your first script#

A companion app is a loop: read what the robot is doing, decide what the panel should look like, push it. Here is the whole shape of one.

from bb import Board

with Board.open() as board:
    leds = board.led_layer()

    while True:
        arm_fault = read_from_networktables("arm_fault")
        in_range  = read_from_networktables("in_scoring_range")

        leds.set(3, "red" if arm_fault else "off")
        leds.set(7, "green" if in_range else "off", fx="breathe")
        leds.flush()

Why led_layer() and not board.led()#

Both work. The difference is what happens when nothing changes.

board.led(3, "red") sends a command every time you call it. In a 50 Hz loop that is 50 commands a second per button, whether or not the colour changed — the board processes all of them and puts the changes on the bus.

led_layer() stages the writes and flush() sends only what changed. A steady panel costs nothing at all. Use it for anything that runs in a loop; use board.led() for one-off changes.

leds.set(3, "red")
leds.flush()        # sends: led 3 FF0000
leds.set(3, "red")
leds.flush()        # sends nothing

Colours#

Anything sensible works:

leds.set(1, "red")             # a name
leds.set(2, "#0040FF")         # hex, with or without the #
leds.set(3, (0, 64, 255))      # an (r, g, b) triple
leds.set(4, 0x0040FF)          # an int
leds.set(5, None)              # off

Named colours include red green blue yellow cyan magenta orange purple pink amber lime teal white off, plus alliance_red and alliance_blue.

Effects#

leds.set(3, "red", "blink")       # slow flash
leds.set(3, "red", "fast")        # fast flash
leds.set(3, "red", "breathe")     # fade in and out

The tile generates the effect, so it keeps running with no further commands.

Clearing up#

board.led_reset()      # back to the colours saved in the configuration
board.led_all("off")   # everything dark, right now

led_all("off") is the panic button — it takes priority over anything else in progress.

When the board goes away#

A companion app runs for a whole match, and USB cables get kicked. Every call raises rather than failing quietly:

from bb import Board, BoardError

try:
    leds.flush()
except BoardError as e:
    print("lost the panel:", e)
    # reconnect, then leds.forget() so the next flush redraws everything

forget() matters after a reconnect or a reboot: the diffing layer thinks the board still shows what it last sent, and after a power cycle that is no longer true.
